src/afw/doc/
------------

This directory contains the doc for Adaptive Framework core.

The Syntax EBNF railroad diagrams are generated by the docs build
(afwdev build --docs) from src/afw/generated/ebnf/syntax.ebnf. See
developer/compiler-ebnf.md.

Writing handbook XML
--------------------

The docs builder (src/afw_dev/_afwdev/build/docs/docs.py) knows these
elements; it reports any other element as unknown.

  <literal>    Inline code: a name, value or short command in a sentence.
  <code>       A code block, always rendered as its own block (<pre>), so
               never put it inside <paragraph>, <item> or <column>. Use
               <![CDATA[ ... ]]> for code with < or &, or ref="file" to
               include a file.
  <link>       href="..." is required; the text is the text attribute or
               the element's content. Links to other guide pages use the
               .html name (href="indexes.html").
  <steps>      An ordered list of <step> elements.
  <object-type-table objectTypeId="..." [srcdir="..."]/>
               A table of an object type's properties, from generated
               metadata; srcdir names the extension that defines it.

Text in <paragraph> is not escaped again, so write &amp;lt; for a literal
"<" there; text in <literal> and <code> is escaped for you.

Check a change with ./afwdev build --docs.
